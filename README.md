The IoT-Based Plant Monitoring System demonstrates a practical integration of sensing, embedded processing, Wi-Fi communication, cloud-connected visualization and automatic actuation. NodeMCU ESP8266 provides the central control and communication functions, while DHT11 and soil-moisture sensing provide the required plant-environment information.
The relay-controlled pump enables automatic irrigation based on soil moisture. The Blynk dashboard makes the measurements available remotely and provides a convenient interface for manual control. The prototype therefore provides a useful foundation for smart gardening and can be expanded with additional sensors, better calibration, alerts and renewable power.
